# Genemon — the master list of lists

> **Summary (read this first)**
> 1. One section per content list: axes, spaces, elements, the type chart, reactions, grounds, weathers, foods, experiences, body kinds, patterns, size classes, wild census, statuses, move shapes, moves, ledger events, achievements, quests, quest givers, reward items.
> 2. Every table between `<!-- GEN:x -->` markers is generated from the code by the scripts in Appendix A — never hand-edit a number, regenerate.
> 3. Each section ends with **Expand** (what a new entry needs, file by file) and **Balance notes** (gaps measured in the current data, not guessed).
> 4. Measurements come from the real modules: a 20,000-genome census through `express()`, `moveCost()`, `typeMultiplier()`, arenas generated by `src/world/arena.ts`, real `Battle` and auction ledger rows, and the scenario fixtures of `docs/SCENARIOS.md`.
> 5. `tests/content_test.ts` fails when any id in the code is missing from this file; the five biggest risks are summarised right below.

## Why this document exists

Genemon is built from many small lists that interlock: an axis feeds an element signature, which decides a type, which picks moves, whose effects change the ground, whose properties change the damage, which the ledger records, which achievements and quests count. A change to one list silently breaks another. This file puts every list in one place with the wiring needed to extend it and the gaps that already exist, and it is generated so it cannot drift from the code without a test noticing.

## The five biggest balance risks (measured)

1. **Light dominates the wild and the move table.** Luminance is an `extreme`-dominance axis and light's signature is almost pure luminance, so light is 24.7 % of wild primaries while metal is 1.5 % and ice 2.7 % (§13). Light also owns the best projectile (Photon Dart, 47.5 dmg/s at 0.98 accuracy) and the strongest beam (Solar Beam, power 95), and raising a Genemon on lava makes it light more often than fire (SC-31). Expect a light-heavy meta with shadow/void as forced counters.
2. **Weather and terrain shapers are almost unreachable.** `weatherShaper` needs wisdom > 0.2 plus > 0.42 affinity to air/water/ice/light/shadow, and `terraformer` needs > 0.48 earth/plant/ice/fire affinity: only 0.1–4.8 % of wild Genemon can learn any given weather or terrain move, and heatwave/sandstorm/storm/acid-rain calls sit at 0.2–0.5 % (§13). The mechanics showcased by SC-06/SC-07 will barely appear in play.
3. **Size economy.** XS is strictly worse than S for the same slot (budget 0.85 vs 1.0; wild power 77.6 vs 91.3), and lone M/L/XL bodies sit 10–12 % above the budget that ties an equal-slot swarm in a focus-fire duel (§12, SC-11): big bodies win slot-for-slot and XS is never picked. `battle.ts` widens the gap: contact hits scale with the mass ratio (x0.75 to x1.4, steeper for mass-scaled slams).
4. **Move costs reward slow charges and over-price status riders.** The tempo term makes 1.5 s beams the cheapest power per energy (Solar Bloom 3.38, Solar Beam 3.06 vs a 1.83 mean) while status riders are priced by chance x duration whatever they are worth, so water moves cost 42-48 % more than their fire twins (Tide Slam 34 vs Ember Bite 24, Water Jet 31 vs Cinder Spit 21, Hydro Beam 42 vs Flame Lance 29 energy) for a *wet* rider that deals no damage itself (§16). No move removes a status.
5. **Chart and reaction coverage gaps.** Metal resists 7 of 14 elements yet is the rarest type; plant is resisted by 5 and no weather ever boosts plant or metal; neutral, psychic and void take part in no reaction; and element notes promise interactions no reaction implements (metal rusts in water, psychic purges poison, plant absorbs light, void swallows air) (§3–§5).

Smaller risks, each in its section: physical-only experiences pay more XP per unit than sofa ones (§9), lifestyle cannot move `phase`, `stature` or `reach` (§1), the Mirror Lake arena is only ~15 % liquid so electric's ground edge rarely shows (§6), day and night switch abruptly at 07:00 and 19:00 (§1), and giver arcs unlock on absolute community counts that small towns never reach (§20).

**Expand.** Add the id to `AXIS_IDS` and an `AXES` row (poles, group, dominance, note); put it in a `SPACES` group; give it at least one food, experience or ground nudge (`src/data/lifestyle.ts`) and decide whether an element signature uses it (`src/data/elements.ts`). Warning: `genomeId()` folds every allele, so a new axis changes every existing genome id (and NFT token id) — plan a migration.

**Balance notes.**
- Four axes use `extreme` dominance (luminance, substance, altitude, form): the allele farther from zero wins, so these axes express larger magnitudes than additive ones. Luminance and substance carry the light, shadow and void signatures — the root of the element skew in §13.
- No food, experience or ground nudges `phase`, `stature` or `reach`: they are genetic only (fusion adds +0.3 stature; battles nudge phase through element signatures). Size class is effectively fixed at birth apart from growth.
- `stature`, `might`, `sociality`, `mood`, `appetite` and `reach` appear in no element signature (they shape body and behaviour, not type) — intended.
- `rhythm` is read by `battle.ts`: attack x (1 ± 0.06 x rhythm) with a hard day/night switch at 07:00 and 19:00 local time, and light/shadow swing x1.1 / x0.9 with the clock (SC-09, SC-12). A step invites timing battles to the minute; `epigenetics.ts` already uses a smooth cosine.

**Expand.** `ELEMENT_IDS` + an `ELEMENTS` row (colour, core, signature, note); a `CHART` row and an entry in other rows' columns; at least one reaction; name syllables (`SYLL` in `phenotype.ts`); five or more moves (melee, projectile, beam, burst, one utility) including a tier-3; a ground affinity; a weather that boosts it; ability gates in `express()` if it should shape weather or terrain.

**Balance notes.**
- `neutral` has no strengths by design and is resisted by earth, metal and void.
- `plant` is the weakest attacker (offence -3, resisted by 5 elements) and no weather ever boosts it.
- `metal` is the best defender (+4, resists 7 elements) and the rarest wild primary (1.5 %); no weather boosts it either.
- `earth` is the best all-rounder (+2 / +2); `void` hits four elements x2 and is weak only to light.
- `light` scores -1 / -1 on the chart yet is the most common wild primary (24.7 %): its power is population and move stats, not the chart.
- Element notes promise interactions no reaction implements: metal "rusts in water", psychic "purges poison", plant "absorbs light", void "swallows air and minds".

## 17. Ledger events — the content contract

Achievements, quest steps and quest-giver arcs are all `Trigger { what, count, where?, filter? }` evaluated on ledger rows (`src/core/ledger.ts`) by `triggerMatches()` in `src/data/achievements.ts`:

- `what` — the event name (`GEvent.what`), one of the rows below.
- `count` — progress needed; each matching row adds `eventWeight()` = its numeric `entries.units` (km, portions, gifts) or 1.
- `where` — optional `GEvent.where.space` (e.g. `physical`) or `where.zone`.
- `filter` — every condition must hold. Key syntax `[entries.|exits.]key[>=|<=|!=]`: an unscoped key is looked up in `entries`, then `exits`, then (for `from` / `to`) the GEvent envelope; `>=`/`<=` compare numbers; `!=` negates; the value `ME` (`"$me"`) matches the player whose progress is counted (`market.sold` `sellerId: ME`). Keys must exist in the event's contract with the declared domain (the test enforces it); keys marked `+` are *requested* from the emitter and cannot progress yet.
- **Attribution** — a row counts for player P when `who` is P or one of P's Genemon; system rows (`battle.end`, `market.sold`) are matched with `ME` filters instead.
